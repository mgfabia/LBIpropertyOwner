ISSUES TO BE AWARE OF:

1. COMMERCIAL PURPOSE — The certification above states non-commercial.
   If you plan to use this data in any product, service, or activity
   where you expect profit (even indirectly), you must certify it as
   commercial instead. Commercial requests get 14 business days
   instead of 7, and the custodian can charge up to 2x reproduction
   cost. Intentionally failing to certify commercial use carries civil
   penalties: $1,000 first offense, $2,500 second, $5,000 subsequent.

2. DANIEL'S LAW REVIEW — Because this request includes owner names,
   the custodian must review for Daniel's Law protected persons
   (judges, prosecutors, law enforcement). This extends the response
   deadline from 7 to 14 business days per N.J.S.A. 47:1A-5(m).
   Expect a 14-day turnaround, not 7.

3. FORM REQUIREMENT — The GRC requires OPRA requests to be on the
   agency's official form or a written equivalent containing ALL the
   form's required fields (name, address, phone, email, certifications).
   This draft includes all required fields. However, Ocean County may
   have their own OPRA portal or form — check their website first. If
   they have a web portal (GovQA, JustFOIA, etc.), use that instead
   of emailing this letter, as it guarantees proper routing and
   creates a trackable record.

4. SPECIAL SERVICE CHARGE RISK — Low. The tax assessment list is a
   standard maintained database, not a custom compilation. If they
   claim extracting it requires "extensive effort" and try to impose
   a special service charge, you can push back — the data exists in
   electronic format and OPRA requires they provide it as maintained.
   If they insist, ask for an itemized cost breakdown. If you disagree
   with the charge, the request is considered denied and you can file
   a complaint with the GRC within 45 days.

5. DENIAL RISK — Very low for this type of request. Tax assessment
   lists are standard public records requested routinely. The only
   likely partial denial is Daniel's Law redactions, which are
   expected and acceptable. If fully denied, the custodian must cite
   a specific legal basis. You have 45 days to file a complaint with
   the GRC (no filing fee).

6. IF NO RESPONSE IN 14 BUSINESS DAYS — Silence is a deemed denial
   under OPRA. You can file a Denial of Access Complaint with the GRC
   at https://www.nj.gov/grc/register/ (free, no attorney needed).

7. ALTERNATIVE TARGETS — If the county Tax Board is unresponsive, you
   can file the same request with each municipality's tax assessor
   individually (6 separate requests). Municipal clerks are the
   designated OPRA custodians for most municipalities.
